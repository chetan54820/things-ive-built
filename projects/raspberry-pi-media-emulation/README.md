# 🎮 Raspberry Pi Media & Emulation Centre

A Raspberry Pi 5 configured as a combined living-room media centre and retro gaming machine.

## Stack

- Raspberry Pi 5
- Debian / Linux
- Kodi
- RetroArch
- EmulationStation
- NAS / network storage
- Game controller

## What it does

The Pi acts as one box for both media playback and retro gaming. Kodi handles the media-centre side while RetroArch provides emulation, with games and media stored on network storage.

## Why I built it

I wanted a flexible Linux-based system rather than a collection of separate appliances. The fun is in making the operating system, applications, storage and controller all behave like one coherent living-room device.

## Areas explored

- Linux configuration
- Retro emulation
- Kodi media organisation
- Network storage
- Controller configuration
- HDMI display / audio setup
- Performance and troubleshooting
